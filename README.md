# PROTOCOL // VALOR — 5v5 Browser Tactical Shooter

A browser-native 5v5 tactical FPS built with Three.js, PeerJS WebRTC, and Web Audio.

## Controls
- **Move / Walk / Crouch / Jump:** `W A S D` / `Left Shift` / `Left Ctrl` / `Space`
- **Fire / ADS & Dual-Zoom:** `Left-Click` / `Right-Click`
- **Weapons:** `1` Primary • `2` Sidearm • `3` Karambit • `4` Plant/Defuse Spike • `R` Reload • `G` Drop • `Y` Inspect
- **Abilities:** `C` Basic 1 • `Q` Basic 2 • `E` Signature • `X` Ultimate
- **Menus & Comms:** `B` Armory Buy Menu • `P` Settings & Ray Tracing • `Tab` Scoreboard • `CapsLock` Tactical Map • `Z` Ping • `T` Wall Spray • `Enter` Team Chat
